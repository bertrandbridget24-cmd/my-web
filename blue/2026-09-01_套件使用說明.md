## 一、新頁面怎麼套用

在 `<head>` 裡加這幾行：

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+TC:wght@300;400;500;700&family=Noto+Serif+TC:wght@500;700&display=swap" rel="stylesheet">

<link rel="stylesheet" href="assets/css/tokens.css">
<link rel="stylesheet" href="assets/css/layout.css">
<link rel="stylesheet" href="assets/css/cards.css">   <!-- 用到首頁卡片才需要 -->
<link rel="stylesheet" href="assets/css/pages.css">   <!-- 內頁才需要 -->
<link rel="stylesheet" href="assets/css/effects.css">
```

在 `</body>` 前加這幾行：

```html
<script src="assets/js/site-data.js"></script>
<script src="assets/js/render.js"></script>
<script src="assets/js/ocean.js"></script>
<script src="assets/js/ui.js"></script>
```

**載入順序不要調換。** `site-data.js` 要在 `render.js` 前面、`render.js` 要在 `ocean.js` 前面 ——
因為卡片和星星是 `render.js` 產生的，`ocean.js` 得等它們存在才抓得到。
CSS 也一樣：`tokens.css` 定義了所有顏色變數，其他 CSS 都依賴它，要放最前面。

只有用到首頁那種卡片才需要 `cards.css`；只有內頁才需要 `pages.css`；只有用到特效才需要 `effects.css` 和 `ocean.js`。

### 內頁的 body 要帶 class

內頁的 `<body>` 要加一個 `page-xxx` class，用來決定該頁的強調色（標題顏色、分隔線顏色）：

```html
<body class="page-cooking">        <!-- 深海藍 -->
<body class="page-web-design">     <!-- 海洋藍 -->
<body class="page-other-works">    <!-- 湖水藍 -->
<body class="page-services">       <!-- 青藍   -->
```

原理是 `pages.css` 只替各頁換掉 `--page-accent` 這一個變數，元件本身的 CSS 只有一份。

## 二、特效怎麼呼叫

不用再複製一大串 `<svg>` 和 `<i>`，只要寫一個 `data-ocean` 屬性。

| 寫法 | 效果 |
|---|---|
| `<div data-ocean="bubbles" data-count="9"></div>` | 背景上升的氣泡 |
| `<div data-ocean="fish" data-count="8"></div>` | 悠游的小魚 |
| `<div data-ocean="seabed" data-weeds="10" data-crab="1"></div>` | 海草＋螃蟹 |
| `<a data-ocean="btn-bubbles" data-count="5">按鈕</a>` | 滑鼠移上去冒泡泡 |
| `<a class="card" data-ocean="card-fx" data-bubbles="6" data-pearls="9">…</a>` | 卡片冒泡泡＋長珍珠串 |
| `<div data-ocean="nightsky" data-moon="孫" data-stars="欣,黑糖"></div>` | 夜空月亮＋星星，滑上去顯示對應的字 |
| `<div data-ocean="jellyfish" data-count="7"></div>` | 背景漂浮水母（內頁背景層） |

### 注意事項

- `bubbles`、`fish` 要放在 `position: relative` 的容器裡（例如 `.hero`），才會蓋滿整塊。
- `seabed` 要放在 `.cta-band` 這種底部區塊裡，容器需要 `overflow: hidden`。
- 不要螃蟹：`data-crab="0"`。
- 想換一組隨機排列：加 `data-seed="12345"`。同一個 seed 每次結果都一樣，方便微調到滿意為止。

### 背景水母 jellyfish

放在 `<body>` 的最前面就好，它是 `z-index: -1` 的固定背景層：

```html
<body class="page-cooking">
    <div data-ocean="jellyfish" data-count="7"></div>
```

- 水母會畫在**頁面底色之上、白色卡片之下**，只在卡片之間和左右留白露出來，不會壓到內容。
- 位置固定在畫面上（`position: fixed`），捲動時內容會從水母前面滑過去，有淡淡的景深感。
- 因為內容都集中在畫面中間，水母是**刻意安排在左右兩側的留白**，不然會整隻躲在卡片後面看不見。
- 這一層順便替頁面底色加了一道很淡的水藍漸層，白色卡片才不會浮在一片死白上。
- 視窗寬度 768px 以下只留兩隻（手機上卡片幾乎佔滿寬度，放多了也看不到）。
- 首頁也有（5 隻，比內頁少）。Hero 和結尾 CTA 區塊都有自己不透明的背景，會把水母擋住，所以牠們只會出現在中間那段淺色區域。

### 夜空 nightsky

- 要用夜空，外層區塊要加上 `night` class：`<section class="cta-band night">`。加了之後背景會變成夜色漸層，海草和螃蟹自動壓暗成剪影。
- `data-moon` 是滑到月亮時顯示的字，留空就不放月亮。
- `data-stars` 用逗號分隔，有幾個字就有幾顆星星，**最多 8 顆**（目前用 7 顆）（也可以直接在後台的「夜空星星」頁籤改）（位置是排好的，避開中間的文字欄）。超過的會在主控台跳提醒。
- 星星位置寫在 `ocean.js` 的 `STAR_SPOTS`，想搬位置就改那個陣列的 `top` / `left` / `size`。
- **`top` 不要小於 22**，否則星星會落在上方淺色的海浪上看不見；提示文字也會自動改成往下顯示。
- 靠左右兩側的星星（`left < 14` 或 `> 80`），提示文字會自動改成貼齊自己的邊，名字長也不會被區塊裁掉。

### 星星藏小遊戲

**一顆星星可以配一個遊戲，同一個遊戲也可以掛在好幾顆星星上。** 對應關係寫在 `data-games`：

```html
<div data-ocean="nightsky" data-moon="孫" data-stars="欣,哥哥,雨"
     data-games="欣:starship,哥哥:maze,雨:fishing,尤國任教授:life"></div>
```

實際上不用手寫 —— **到後台的「夜空星星」頁籤，每顆星星都有一個下拉選單**，選好按匯出就好。

目前有四個遊戲：

| 代號 | 遊戲 | 需要載入 |
|---|---|---|
| `starship` | 飛船射擊 深海巡航（目前配「欣」） | `game.css` + `starship.js` |
| `fishing` | 釣魚 淺海垂釣（目前配「雨」） | `game.css` + `fish.css` + `fishing.js` |
| `maze` | 迷宮 深海迷宮（目前配「哥哥」） | `game.css` + `maze.css` + `maze.js` |
| `life` | 人生選擇 潮汐之間（目前配「尤國任教授」） | `game.css` + `life.css` + `life.js` |

四個都要再加 `game-hub.js`（負責點星星時開對應的遊戲）。有被指定遊戲的星星會多一圈脈動光暈提示可以點。

**遊戲的 HTML 結構寫在 `services.html` 的 `</body>` 前面。** `fishing.js`、`maze.js` 和 `life.js` 是靠 `id` 或 `data-life` 抓元素的（`fishing-overlay`、`maze-walls`、`maze-player`、`life-overlay`、`data-life="stage"`…），**那些名字不能改**，我在 HTML 裡有註解標出來。

**深海巡航**：3 條命，擊落水母每隻 10 分，每 10 隻進一關，第 3 關開始水母會反擊。桌機用 ← → 移動、空白鍵射擊；**觸控裝置改成自動射擊**，只要拖曳移動就好。
**淺海垂釣**：30 秒，點畫面下鉤，碰到魚自動收線。淺藍 10 分、米白 30 分、深藍 50 分。
**深海迷宮**：21×21，操控**會發光的珍珠**從左上走到右下角的**海星**，計時。桌機用方向鍵或 WASD；**沒有鍵盤的裝置會出現虛擬方向鍵，按著不放可以連續走**。
**潮汐之間**：七章，每章一個二選一。**選完會先看到「後來發生了什麼」再進下一章**，而且**第一章和第四章的選擇會改變後面遇到的場景**（走資訊社線和烘焙社線是完全不同的故事）。最後依「技術／生活」的比例給結局，**共 7 種**，其中兩個是隱藏的：七題全選冒險的選項、或七題全不選，各有一個。結局還會列出你這一路做過的七個選擇。純文字，手機桌機都能玩。

四個遊戲都可以用 Esc 或點視窗外關閉。最高分存在瀏覽器的 localStorage，只留在自己電腦上。

## 二之二、後台 admin.html

**用瀏覽器打開 `blue\admin.html`，密碼是 `catherine`。**（想改密碼：`assets/js/admin.js` 最上面的 `PASSWORD`）

### 可以改什麼

左邊七個頁籤：首頁、個人介紹、烹飪作品、網頁作品、其他作品、其他服務、夜空星星。
每一頁的標題、副標、內文、按鈕文字與連結都能改；卡片可以**新增、刪除、上下移動排序**。

### 圖片兩種給法

1. **下拉選現有檔名** —— 你先把圖片複製到 `my-web-main` 資料夾，後台的下拉選單就會有。這種方式資料檔很小、畫質不損。
2. **直接拖圖進來** —— 會自動縮到最寬 1200px、轉成 JPEG 再嵌進資料檔。方便，但每張圖會讓資料檔大幾百 KB。

平常建議用第 1 種，臨時測試用第 2 種。

### 工作流程

```
在後台改 → 按「預覽這一頁」看實際效果 → 滿意 → 按「匯出 site-data.js」
→ 把下載到的檔案蓋回 blue\assets\js\site-data.js → 完成
```

- **沒有匯出就不算真的更新網站。** 修改會自動存成草稿（存在瀏覽器裡），關掉分頁再回來還在，但正式頁面看到的還是舊的。
- 「預覽這一頁」會用網址後面加 `?draft=1` 開新分頁，顯示的是草稿。網址沒有 `?draft=1` 的就是正式內容。
- 改壞了按右上角「還原成預設」，會回到 `site-data.js` 目前的內容。

### 為什麼要「下載再蓋回去」這一步

瀏覽器基於安全考量，**不允許網頁直接寫入你電腦上的檔案**。所以任何在瀏覽器裡跑的後台，最後一定得經過下載。要省掉這一步只能架一台真的伺服器（Node.js/PHP），那樣每次要用後台都得先把伺服器開起來。

## 二之三、手機與平板（RWD）

### 漢堡選單

視窗寬度 900px 以下、**或是任何沒有滑鼠的裝置**，導覽列會收成漢堡按鈕。

判斷條件是 `@media (max-width: 900px), (hover: none), (pointer: coarse)` —— 只看寬度的話，iPad 橫向有 1024px 卻沒有鍵盤滑鼠，會拿到桌機版選單，所以多加了後兩個條件。

行為：點漢堡展開、再點收合、點選單裡的連結自動收合、點選單外面或按 Esc 也收合、視窗拉寬回桌機尺寸時自動歸零。按鈕是 44×44px（手指好按的最小尺寸），展開時三條線會轉成叉叉。

### 觸控裝置防呆

iOS 上快速點兩下會被系統當成「選字」或「放大」，遊戲就會卡住不能玩。所以遊戲介面全部加了：

```css
user-select: none;              /* 不能選字 */
-webkit-touch-callout: none;    /* 長按不跳出拷貝選單 */
touch-action: manipulation;     /* 關掉雙擊放大，順便消除 300ms 點擊延遲 */
-webkit-tap-highlight-color: transparent;
```

畫布再多一層 `touch-action: none`，不然在畫布上拖曳會變成捲動整個頁面。

**飛船射擊在觸控裝置改成自動射擊。** 因為「拖曳移動」和「點擊射擊」在手機上是衝突的手勢 —— 你不可能一邊拖著閃躲、一邊點擊開火。改成自動連射之後，手機玩家只要專心移動就好。桌機維持空白鍵手動射擊。

## 四、已知限制

1. **字型需要連網。** 離線開啟會退回系統字型（微軟正黑體），版面不會壞，但質感會差一截。
2. **特效需要 JavaScript。** 關掉 JS 的話，文字、圖片、排版、顏色全部正常，只有小魚／海草／泡泡不會出現。導覽列和頁尾是寫死在 HTML 裡的，不受影響。
3. **後台不能直接存檔，一定要下載後手動蓋回去。** 原因見上面「二之二」。
4. **三個作品細節頁（diy / illustration / photography）沒有納入後台。** 那三頁是單一作品的詳細介紹，每一頁結構都不同，目前還是直接改 HTML。需要的話再跟我說。
5. **導覽列和頁尾沒有拆成共用檔。** HTML 本身沒有「引用另一個 HTML」的功能，而 `fetch()` 在 `file://` 下會被瀏覽器擋掉。目前是每頁各自保留一份 HTML；如果之後要改成共用，可以再用 JS 注入的方式處理。
6. **系統設定「減少動態」時**，所有動畫會自動關閉，小魚和螃蟹會靜止散佈在畫面上，不會消失。
7. **小遊戲需要 JavaScript 和 canvas。** 現在的瀏覽器都支援，但關掉 JS 就沒有了。遊戲只有點下去才會載入執行，不影響一般瀏覽速度。
8. **夜空的字只有滑鼠移上去才看得到。** 觸控裝置沒有 hover，手機使用者點一下星星會顯示（瀏覽器的行為），但不保證每支手機都一樣。這是彩蛋性質的設計，不要放重要資訊在裡面。
